# Component 1 — Web Application Documentation

## Technology Stack
- Vanilla HTML5 & CSS3 Design System
- Modern Vanilla JavaScript (Fetch API)
- Chart.js for Infrastructure Analytics
- Responsive Layout with dynamic role-based navigation sidebar

## Page Routes
1. `/pages/M1/microgrids.html`: Microgrid node list, search, status filter, and status toggles.
2. `/pages/M1/create-microgrid.html`: Microgrid node registration form.
3. `/pages/M1/edit-microgrid.html`: Microgrid properties editor.
4. `/pages/M1/microgrid-details.html`: Telemetry details view.
5. `/pages/M1/energy-capacity.html`: Visual progress indicators for total, available, reserved, and used capacities.
6. `/pages/M1/battery-storage.html`: Battery storage levels, charge percentages, and status updates.
7. `/pages/M1/energy-availability.html`: Available energy discovery browser.
8. `/pages/M1/energy-slots.html`: Energy slot publishing, management, and cancellation.
9. `/pages/M1/dashboard.html`: Infrastructure statistics dashboard with Chart.js charts.
